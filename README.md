# ⚡ VLESS Speed Finder & Subscription Server

Полноценный, высокопроизводительный веб-сервис на **FastAPI** для автоматического парсинга, параллельной проверки задержки/стабильности и выгрузки **5 самых быстрых и стабильных VLESS конфигураций**.

Подходит как для личного использования (через удобный веб-интерфейс или единую ссылку подписки), так и для разворачивания собственного публичного или приватного агрегатора VLESS-конфигураций.

## 🌟 Руководство для Пользователей

### Что такое VLESS и как это работает?
**VLESS** — это легкий и производительный протокол передачи данных без сохранения состояния (stateless), используемый для безопасного и анонимного обхода блокировок.

Этот сервис автоматически объединяет десятки открытых источников с VLESS-конфигурациями, тестирует каждый узел на реальную доступность, измеряет задержку (пинг в миллисекундах) и формирует список из **5 самых быстрых и стабильных узлов**.

---

### Возможности веб-интерфейса

1. **🏆 Топ-5 лучших узлов в реальном времени:**
   - Карточки с медалями (#1 Золото, #2 Серебро, #3 Бронза).
   - Индикаторы задержки с цветовой кодировкой:
     - 🟢 **До 300 мс** — Отличная скорость для стриминга и игр.
     - 🔵 **300 - 600 мс** — Стабильный доступ для повседневного веб-серфинга.
     - 🟡 **Свыше 600 мс** — Допустимая скорость для мессенджеров.
   - Теги протоколов шифрования и транспорта (`TCP / REALITY`, `WS / TLS`, `gRPC / TLS`, `xHTTP`).

2. **⚡ Удобное копирование и QR-коды:**
   - **Скопировать все (Copy All Top 5):** Позволяет скопировать сразу 5 VLESS ссылок в буфер обмена в один клик.
   - **Скопировать отдельно:** Кнопка копирования на каждой карточке.
   - **QR-код (QR Code):** Нажмите на кнопку QR на карточке, чтобы отсканировать конфигурацию напрямую камерой телефона.

3. **📊 Панель статуса и прогресс сканирования:**
   - Отображает количество найденных и рабочих узлов, дату последнего сканирования и шкалу прогресса.
   - Кнопка **«Запустить сканирование»** позволяет вручную обновить список узлов.

### Как подключить подписку в клиентах

Единая ссылка подписки подставляет 5 лучших серверов прямо в ваше приложение и автоматически обновляет их при запуске сканирования.

Ссылка подписки: `http://<ВАШ_ИП_ИЛИ_ДОМЕН>:8000/api/vless/sub`

#### 📱 Android
- **v2rayNG:** Нажмите `☰` -> `Подписки` -> `+` -> Вставьте ссылку подписки -> Нажмите `⋮` -> `Обновить подписку`.
- **NekoBox:** Нажмите `☰` -> `Группы` -> `+` -> Тип: `Subscription` -> Вставьте ссылку.

#### 🍏 iOS (iPhone / iPad)
- **Shadowrocket:** Нажмите `+` в правом верхнем углу -> Тип: `Subscribe` -> Вставьте URL.
- **Streisand:** Перейдите в раздел `Subscriptions` -> `+` -> Вставьте ссылку.

#### 💻 Windows / macOS / Linux
- **v2rayN:** `Subscription setting` -> `Add` -> Вставьте URL -> `Update subscription`.
- **Sing-Box / NekoRay:** Раздел `Groups` -> `Add Subscription` -> Вставьте URL.
- **PassWall (OpenWrt):** Раздел `Node Subscribe` -> `Add` -> Вставьте URL -> `Save & Apply`.

### Объяснение протоколов и задержек

- **REALITY (XTLS):** Современный метод маскировки трафика под легитимный TLS-трафик крупных сайтов (Google, Microsoft, Apple) без необходимости покупки собственного домена.
- **TLS / WS (WebSocket):** Маскировка трафика под обычные веб-сокеты, часто используемая для маскировки за CDN (Cloudflare).
- **gRPC:** Высокоскоростной транспорт на базе HTTP/2.
- **xHTTP / SplitHTTP:** Протокол для обхода глубокого анализа пакетов (DPI) и жёстких фаерволов.

### Архитектура и структура проекта

Приложение написано на **FastAPI** и использует асинхронный цикл событий `asyncio` для управления фоновыми задачами и процессами **Xray Core**.

```
.
├── app/
│   ├── main.py               # Точка входа FastAPI, инициализация, static/templates, lifespan
│   ├── config.py             # Централизованная конфигурация и параметры среды
│   ├── api/
│   │   └── routes.py         # REST API маршруты (/api/vless/*, /api/scan/*)
│   ├── services/
│   │   ├── scanner.py        # Асинхронный движок проверки VLESS через SOCKS пулы Xray
│   │   └── subscription.py   # Генератор подписок (Base64/Raw) и нормализатор VLESS URI
│   ├── static/
│   │   ├── style.css         # Стили CSS Glassmorphism с неоновым свечением
│   │   ├── script.js         # Frontend скрипт (Polling API, Render cards, Modal, QR)
│   │   └── qrcode.min.js     # Автономная библиотека генерации QR-кодов
│   └── templates/
│       └── index.html        # HTML5 шаблон веб-панели управления
├── tests/
│   └── test_api.py           # Набор автоматических тестов API
├── config.txt                # Список URL источников VLESS подписок
├── top5.txt                  # Результат: 5 лучших VLESS ссылок
├── results.json              # Результат: Подробная статистика последнего сканирования
└── README.md                 # Документация проекта
```

---

### Алгоритм работы и тестирование Xray Core

1. **Скачивание и Парсинг:**
   - Сканер считывает ссылки из `config.txt`.
   - Загружает содержимое асинхронно через `aiohttp`.
   - Декодирует Base64 при необходимости, извлекает валидные VLESS URI с помощью регулярных выражений и удаляет дубликаты по дедупликационному хэшу.

2. **Динамический SOCKS-пул Xray:**
   - Для пачки VLESS узлов создаётся временный конфигурационный JSON для **Xray Core**.
   - На каждый узел назначается уникальный локальный SOCKS5 порт (`PORT_START = 10000`).
   - Запускается единственный фоновый процесс `xray run -config temp.json`.

3. **Измерение задержки и проверка доступности:**
   - Через локальные SOCKS5 прокси отправляются параллельные HTTP GET запросы на контрольный URL (`https://www.gstatic.com/generate_204`).
   - Измеряется задержка соединения (пинг в мс).

4. **Повторная проверка и сортировка:**
   - Топ кандидатов проходит повторную проверку (`RECHECK_ATTEMPTS`) для подтверждения стабильности.
   - Сортировка выполняется по критериям: `Стабильность (отсутствие потерь пакетов) -> Меньшая задержка -> Количество успешных попыток`.
   - 5 лучших сохранены в `top5.txt` и `results.json`.

### Конфигурация и переменные окружения

Все ключевые настройки задаются в `app/config.py` или через переменные окружения:

| Переменная | Значение по умолчанию | Описание |
| :--- | :--- | :--- |
| `CONFIG_FILE` | `config.txt` | Путь к файлу со ссылками на источники |
| `TOP_FILE` | `top5.txt` | Путь к файлу выгрузки 5 лучших конфигураций |
| `RESULTS_FILE` | `results.json` | Файл полных результатов сканирования |
| `TIMEOUT` | `8.0` | Таймаут подключения к узлу (секунды) |
| `WORKERS` | `100` | Количество параллельных воркеров тестирования |
| `BATCH_SIZE` | `100` | Размер пачки узлов для запуск процесса Xray |
| `TEST_URL` | `https://www.gstatic.com/generate_204` | Контрольный URL для измерения задержки |
| `PERIODIC_SCAN_INTERVAL` | `1800` | Интервал фонового автосканирования (в секундах, 30 минут) |

### Локальный запуск и деплой (Systemd / Docker)

#### 1. Прямой запуск через Uvicorn

```bash
# Клонирование и переход в каталог
cd /path/to/project

# Установка зависимостей
pip install -r requirements.txt

# Запуск FastAPI веб-сервера
PYTHONPATH=. uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```

#### 2. Запуск через Systemd (Linux сервис)

Создайте файл `/etc/systemd/system/vless-finder.service`:

```ini
[Unit]
Description=VLESS Speed Finder FastAPI Server
After=network.target

[Service]
User=root
WorkingDirectory=/opt/vless-speed-finder
ExecStart=/usr/local/bin/uvicorn app.main:app --host 0.0.0.0 --port 8000 --workers 2
Restart=always
RestartSec=5
Environment=PYTHONPATH=.

[Install]
WantedBy=multi-user.target
```

Активация сервиса:
```bash
systemctl daemon-reload
systemctl enable --now vless-finder
```
